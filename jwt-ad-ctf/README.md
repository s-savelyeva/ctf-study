# 🔑 JWT ARENA — A/D CTF сервис с тремя JWT-уязвимостями

Веб-сервис на **Python/Flask** для Attack/Defense CTF. Содержит три независимых
уязвимых приложения (каждое со своим флагом) и общий **современный тёмный веб-интерфейс**
со встроенной JWT-лабораторией (декодер, редактор header/payload, пересборка токена,
подпись HS256 через Web Crypto, отправка запросов, захват флага).

| Порт | Сервис        | Уязвимость                          | Точка с флагом        |
|------|---------------|-------------------------------------|-----------------------|
| 8001 | Legacy Gateway| `alg: none` (отключение проверки подписи) | `GET /api/admin` |
| 8002 | Vault API     | Слабый секрет HS256 → **брутфорс** по словарю | `GET /api/vault` |
| 8003 | Secure Portal | Подмена алгоритма **RS256 → HS256** (публичный ключ как HMAC-секрет) | `GET /api/dashboard` |

Флаг выдаётся только токену с `"role":"admin"` — его нужно подделать соответствующей атакой.

## Быстрый старт

```bash
cd jwt-ad-ctf
python -m venv .venv && . .venv/bin/activate   # необязательно
pip install -r requirements.txt

# все три сервиса одним процессом (dev):
python run_all.py --host 0.0.0.0
# или каждый отдельным gunicorn-процессом (prod-вариант для A/D):
./scripts/run_services.sh
```

Откройте `http://<host>:8001` (`:8002`, `:8003`) — интерфейс сам подскажет эндпоинты.

### Флаги

Задаются через окружение (для A/D их выдаёт orgserver/flow):

```bash
export ALG_NONE_FLAG='FLAG{...}'
export BRUTEFORCE_FLAG='FLAG{...}'
export RS256_FLAG='FLAG{...}'
```

Если не заданы — генерируются случайные при старте процесса.

## Проверенные эксплойты (атакующая сторона)

```bash
python scripts/exploit_alg_none.py      http://HOST:8001
python scripts/exploit_bruteforce.py    http://HOST:8002 scripts/secret_wordlist.txt
python scripts/exploit_rs256_hs256.py   http://HOST:8003
```

Все три скрипта используют только stdlib и реально забирают флаг.

## Как пользоваться веб-интерфейсом

1. Нажмите **«Загрузить токен сервиса»** — в JWT Lab попадёт легитимный токен.
2. **alg:none**: во вкладке *Header* замените `"alg": "none"`, в *Payload* —
   `"role": "admin"`, нажмите «Пересобрать токен» (сигнатуру можно обнулить), затем
   `GET /api/admin`.
3. **Брутфорс**: скачайте токен и переберите секрет офлайн (`hashcat -m 16500` или
   `scripts/exploit_bruteforce.py`), затем вставьте найденный секрет в поле подписи,
   поставьте `role=admin` и нажмите **«Подписать HS256»**, после чего `GET /api/vault`.
4. **RS256→HS256**: кнопка внутри блока «Вставить публичный ключ» сама тянет
   `/public.pem` и подставляет его как секрет; поменяйте роль на admin,
   «Подписать HS256» → `GET /api/dashboard`.

Во вкладке каждой страницы есть блок **«Как это чинить (patch)»** — подсказка для
защищающейся команды.

## Патчи (для defense)

* **alg:none** — игнорировать `alg` из токена; декодировать строго
  `algorithms=["HS256"]`; явно отклонять `none`/пустую сигнатуру.
* **Брутфорс** — `secrets.token_bytes(32)` вместо человекочитаемого секрета;
  ротация через ENV. Словарная проверка при старте: длина < 24 символов или
  наличие в топ-10k паролей → отказ запускаться.
* **RS256→HS256** — фиксировать ожидаемый алгоритм на сервере; никогда не передавать
  public key в HMAC; использовать библиотеки, сверяющие тип ключа с `alg`
  (PyJWT ≥ 2.x, python-jose с `algorithms=[...]`).

## Структура

```
jwt-ad-ctf/
├── app/
│   ├── __init__.py          # фабрики трёх Flask-приложений + healthz
│   ├── jwt_utils.py         # JWT без внешних lib (base64url, HS256, RS256)
│   ├── service_*.py         # точки входа gunicorn по портам
│   ├── templates/index.html # современный UI
│   └── static/{css,js}      # тема + JWT Lab (vanilla JS, Web Crypto)
├── scripts/                 # 3 готовых эксплойта + wordlist + run_services.sh
├── run_all.py               # dev-запуск всех сервисов
├── Dockerfile
└── requirements.txt
```

## Healthcheck (A/D)

`GET /healthz` (и `/health`) на каждом порту — быстрый JSON-ответ без авторизации.
